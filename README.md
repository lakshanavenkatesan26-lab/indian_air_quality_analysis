# Air Quality Analysis and AQI Prediction for Indian Cities

## About the Project
This project analyses air quality data from Indian cities using Python. It studies pollutant levels, finds yearly, seasonal and city-wise trends, and builds a machine learning model to predict the Air Quality Index (AQI).

## Objectives
- Collect and combine public air quality datasets
- Clean the data (missing values, outliers)
- Perform exploratory data analysis (EDA)
- Find which pollutants affect AQI the most
- Build and compare ML models to predict AQI
- Present results with clear visualizations

## Datasets
- Air Quality Data in India (2015-2020), Kaggle (from CPCB)
- CPCB Air Quality Data
- data.gov.in (Open Government Data)
- OpenAQ
- Weather data (Meteostat / IMD)

## Tools and Libraries
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, SciPy, Scikit-learn, Jupyter Notebook

## Workflow
1. Data acquisition
2. Data cleaning
3. Exploratory data analysis
4. Feature engineering
5. Modelling
6. Evaluation
7. Reporting
